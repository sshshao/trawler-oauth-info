Privacy Policy

trawler — last updated 29 September 2026

trawler is a personal, single-operator command line tool that runs on the operator's own computer. It has no server, no user accounts, and no other users. This policy describes what it does with data when it is authorised to read a Gmail mailbox.

What is accessed

  • The single OAuth scope requested is https://www.googleapis.com/auth/gmail.readonly.
  • Within the authorising account's own mailbox, trawler retrieves only messages matching a sender address and label configured by that same person — in practice, newsletters they subscribed to.
  • It reads message metadata and message bodies for those messages only. It does not scan the rest of the mailbox.

What is never done

  • No message is deleted, moved, modified, marked as read, or sent.
  • No data is transmitted to the author of this tool, to any third party, or to any server operated on its behalf.
  • Message content is not used to train models, is not sold, and is not shared.
  • Access is never re-authorised automatically. Authorisation is an explicit, interactive act performed by the mailbox owner.

Where data is stored

  • Retrieved message content is stored in a local SQLite database and local files in the operator's home directory, on hardware the operator controls.
  • The OAuth refresh token is stored in a single local file readable only by the operator's own user account.
  • Nothing is stored anywhere else. There is no cloud component.

Retention and deletion

  • Local data is retained until the operator deletes it. Deleting the local database and output files removes everything trawler has kept.
  • Access can be withdrawn at any time by removing this application at Google Account → Third-party apps & services, or by deleting the local token file. Withdrawal takes effect immediately; the tool does not retain any means of regaining access.

Subscription content

Some collected newsletters are paid subscriptions belonging to the operator. That content is stored and read locally only and is not redistributed, republished, or shared.

Compliance

trawler's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the revised version will be published on this page with an updated date.
