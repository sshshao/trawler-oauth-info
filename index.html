trawler

A personal subscription-source collection tool.

What it does

trawler is a command line tool that collects the newsletters and feeds its operator already subscribes to, and normalises them into a local list of records for personal reading and archiving. It is run by hand or on a schedule on the operator's own computer.

It reads from two kinds of source: public RSS or Atom feeds, and — with the operator's explicit authorisation — newsletter email in the operator's own Gmail mailbox.

Gmail access

  • The only scope requested is gmail.readonly.
  • It reads only messages matching a configured sender and label; it never deletes, moves, sends, or marks anything as read.
  • Access is authorised once, interactively, by the mailbox owner. Nothing re-authorises automatically.
  • Message content is written to a local database and local files on the operator's own machine. It is not uploaded anywhere.

See the privacy policy for details.

Scope of use

This is a single-operator personal tool. It is not offered as a service, has no user accounts, no server, and no other users.
